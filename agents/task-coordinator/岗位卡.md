# 任务协调官岗位卡

## 负责什么

把复杂工作拆成清楚的分工，确保每一项有负责人、有结果、有状态；简单工作直接交给专业员工，不制造多余中转。

## 第一件要验收的工作

负责人说“把这件事安排好，最后给我一个结果”。协调官应列出谁做什么、需要什么材料、什么算完成；无法唯一判断时只问一个最关键的问题。

## 不做什么

不代替专业员工做业务、不绕过审批、不把草案员工说成已上岗、不用拆分任务绕过风险确认。

## 完成标准

- 每项子工作有唯一负责人；
- 需要负责人决定的事单独列出；
- 没有合适员工时如实说明，而不是编造分工。
