# 能力 Plan B 与运行事件架构

本方案在现有 A君模块化单体内补齐能力路由、质量门和排障账本，不新增任务库、队列、调度器或第二套控制台。

## 执行规则

每项外部能力通过小型 `CapabilityAdapter` 登记主路线和最多两条备用路线。统一执行引擎只在以下条件同时成立时自动切换：

- 当前路线为确定失败，而不是结果未知；
- 备用路线的数据等级、副作用不高于原请求；
- 累计最坏费用仍在任务和组织预算内；
- 备用输出通过该能力自己的质量门。

结果未知、认证失败、权限不足、预算越界和策略拒绝都安全停止。外部写入在请求已发出但回执未知时不得换通道重发，避免重复创建、重复扣费或重复发布。

## 小模块边界

| 模块 | 单一职责 |
| --- | --- |
| `workflow/capability-adapter.ts` | Provider 无关的调用接口 |
| `workflow/capability-failure.ts` | 统一故障分类和是否允许恢复/切换 |
| `workflow/capability-routing.ts` | 路线、数据、副作用和预算选择 |
| `workflow/capability-execution.ts` | 有界恢复、Plan B 和 ExecutionReceipt v2 |
| `workflow/capability-event-recorder.ts` | 把执行回执投影为任务运行事件 |
| `task-run-event-*` | SQLite 追加写、脱敏、分页、7/30/365 天分级留存和永久事故摘要 |
| `task-timeline-*` | 面向局域网和本机负责人的不同脱敏投影 |
| `workflow/delivery-*` / `quality-*` / `revision-*` | 交付简报、质量等级、独立复核请求和最多两轮返工契约 |

## 当前接入范围

- 小D ASR：A君模型页可显式选择 StepFun `stepaudio-2.5-asr` 或本机 MLX，任务创建时冻结路线；StepFun 路线不跨服务商回退，响应中断记为 `ambiguous` 并禁止自动重试。字幕、MLX、faster-whisper 与 StepFun 都生成统一回执；仅本机普通任务的确定失败允许降级，降级后必须复核，正式任务不能用低质量模型冒充完成。
- 小R公开网页：静态正文为主路线，现有受控动态网页读取为 Plan B；搜索结果只用于发现，正文、URL、哈希、抓取时间和公开可读验证齐全才可作为证据。
- A君本机视觉：现有受控视觉执行已通过统一引擎记录回执；小D另有本机 FFmpeg 视觉 Adapter 和质量门。
- 外部文档交付：已有结果未知安全停止的 Adapter 契约；具体 Provider 必须显式登记后才能启用备用路线。
- M5 搜索、动态页、PDF、GitHub、图片生成/编辑和配音：调用已通过统一事件桥落任务事件；StepFun 插件继续保留预算门、真实 Provider 回执和 ambiguous 付费调用冻结。当前没有第二个同契约 Provider 的能力会安全停止，不为凑清单伪造备用路线。
- 小D 媒体链路：ASR、视觉质量和飞书持久交付回执会写入与 A君相同的任务事件库；跨进程只传任务 ID 和脱敏回执，不传正文、文件路径或平台凭据。

## 运行事件与任务详情

事件只保存白名单元数据、哈希、脱敏摘要、费用、回执和产物引用，不保存 Prompt、正文、Cookie、Token 或凭据。进度类事件默认保留 7 天、常规明细 30 天、审批/费用/回执等审计事件 365 天；清理故障事件前先固化永久脱敏事故摘要。历史清理默认只预览，必须显式切到 `apply` 才会删除。

任务详情复用现有记录工作台展示“运行过程”。局域网只看业务阶段；本机负责人可展开 Provider、模型、路线、尝试次数、费用、错误代码和回执引用。查询支持故障、切换、费用和质量筛选以及游标续页。

## 质量闭环与诚实边界

DeliveryBrief 和质量等级已进入新任务记录。重要/高风险任务的首轮产出不会直接显示成功，而是自动创建独立审核官子任务；结构化审核通过后才晋升成功，失败时只返工未通过项并保留旧产物，最多两轮，超限或审核结果未绑定会安全停止。缺少必要输入时只问一个关键问题，执行器不会先空跑。

“统一 Plan B”表示所有接入能力遵守同一套切换、安全停止、质量和日志契约，不表示每项能力都凭空拥有第二个供应商。只有已登记、质量等价、数据/副作用和预算都合规的备用路线才会自动切换；单 Provider、认证/权限失败、外写结果未知和质量结果不确定均停止并留下可排查回执。发布验收必须分别说明代码、自动化、运行时、真实 Provider 和人工体验证据，不能用其中一层代替另一层。
