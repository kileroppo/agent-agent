## 1. 核心任务

用户把一个已获授权的音视频来源交给小D，并在飞书内获得可信的整理文档和原始转录。

```text
进入小D → 提交来源与要求 → 等待真实处理 → 必要时补充/审批 → 检查结果 → 使用文档
```

## 2. 主流程

1. 用户进入“小D - 视频转录助手”会话；
2. 发送视频链接，并可补充“整理成文章”等要求；
3. 小D返回任务已接收、任务 ID 和承诺的交付内容；
4. 长任务只在关键阶段更新：获取素材、转录、整理、生成与交付；
5. 完成后返回结果摘要、飞书文档和原始转录入口；
6. 用户打开文档或进入任务详情，不需要转到另一个军团后台完成主任务。

## 3. 分支流程

### 3.1 需要补充信息

- 来源缺失、无效或任务要求无法判断时进入该状态；
- 卡片只问一个当前最关键的问题；
- 用户回复后继续原任务，不创建新任务；
- 低频高级选项按需展开，不在首次提交时一次性询问。

### 3.2 需要审批

- 普通内部文档交付不审批；
- 外部发送、公开发布、敏感访问、临时扩权或超过成本阈值才进入审批；
- 审批卡片明确动作、接收人/范围、风险和有效期；
- 拒绝或过期后不执行目标动作，但保留已生成的安全产物。

### 3.3 可恢复失败

- 说明失败阶段和用户能理解的原因；
- 提供一个主动作，如“继续任务”；
- 从安全 checkpoint 恢复，不重复创建文档或通知；
- 技术堆栈、日志引用和尝试记录放入任务详情。

### 3.4 永久失败或权限不足

- 明确说明不能继续的原因；
- 不显示无效的重试按钮；
- 提供“修改来源”或“查看授权说明”等可行下一步；
- 不暗示系统已经绕过访问控制。

## 4. 能力分级

| 分组 | 能力 | 默认展示 |
| --- | --- | --- |
| 核心 | 提交任务、补充信息、继续任务、查看文档 | 是，紧邻当前任务 |
| 支持 | 原始转录、重新交付、取消任务 | 在相关状态展示 |
| 高级 | 日志、成本、checkpoint、平台同步状态 | 任务详情或 Paperclip |
| 系统状态 | 当前阶段、等待原因、失败和产物校验 | 任务卡片内就近展示 |

## 5. 首屏信息

首屏只包含：

- 当前 Agent 身份与职责；
- 最近或当前任务；
- 当前状态与必要说明；
- 当前唯一主要操作；
- 消息输入框。

部门组织、其他 Agent、历史日志和全局预算不进入小D主任务卡片。

## 6. 响应式优先级

- 桌面端保留飞书侧栏和聊天区；
- 移动端隐藏组织侧栏，保留会话标题、当前任务、主要操作和输入框；
- 关键按钮触控高度不少于 44px；
- 长文档预览在移动端只展示摘要，点击后进入飞书文档；
- 不通过横向滚动展示关键操作。

## 7. 验收问题

- 新用户能否在 10 秒内知道这里是做什么的？
- 当前任务、状态和下一步是否无需展开就能看见？
- 普通任务是否没有无意义审批？
- 错误是否给出可执行的恢复动作？
- 成功是否以可访问产物为中心，而不是以“模型处理完成”为中心？
