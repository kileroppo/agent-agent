## 1. 一句话定义

A君为所有业务 Agent 提供一套可替换的账号连接、内容获取和运维观察底座；Agent 只提出“读取什么内容”，不接触登录信息，也不绑定某个爬虫、下载器、浏览器或插件。

## 2. 用户看到的流程

```text
用户发来链接
→ Agent 请求统一内容获取中心
→ 必要时账号管家请用户自行登录
→ 优先使用该平台的深度获取能力
→ 不能使用时走通用内容获取
→ 返回统一内容包
→ Agent 完成自己的转录、分析、运营或情报工作
```

用户只面对 A君的“连接账号”“重新登录”和“查看状态”入口；不需要启动 `yt-dlp`、MediaCrawlerPro、CookieBridge 或浏览器服务。

## 3. 三项公共能力

| 能力 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 账号管家 | 接收受控浏览器、OAuth、CookieBridge 或本机导入适配器提供的登录状态；管理连接范围、续期、撤销和失效提醒 | 向 Agent、聊天、日志或文档输出原始 Cookie、密码、token 或会话 |
| 内容获取中心 | 识别平台、检查连接、选择适配器、标准化内容包和能力说明 | 让业务 Agent 直接选择底层工具或绕过平台限制 |
| Agent 运维官 | 观察连接、适配器、组件和任务的脱敏健康事件；通知、诊断、低风险重试和恢复 A君自管组件 | 替用户登录、处理验证码、读取凭据、扩大权限或操作账号 |

## 4. 双通道内容获取

```text
内容获取中心
├─ 深度通道：MediaCrawlerPro
│  └─ 固定支持平台；可提供笔记结构、作者、评论等深度能力
└─ 通用通道：yt-dlp / bb-browser / web-access 等受控适配器
   └─ 按自身已登记能力提供正文、图片、视频、字幕和基本信息
```

固定支持平台优先走 MediaCrawlerPro。它不支持或暂时不可用时，内容中心按请求能力切换通用通道。通用通道有自己的明确能力范围，不被称为“内容不完整”；只有用户或 Agent 明确要求某项能力、且没有允许通道能提供时，才说明该能力当前不可用。

## 5. 低耦合规则

- 所有 Agent 只依赖 `ContentAcquisitionContract` 与 `ConnectionAuthorizationContract`；
- 每个工具以独立适配器登记平台覆盖、内容能力、登录要求、版本和健康状态；
- 更换、升级或下线某个工具时，只替换适配器，不修改所有 Agent；
- 账号管家对执行器提供受限连接使用权，不输出原始凭据；
- 内容包统一说明来源、获取通道、实际能力和安全的能力说明；
- 运维官只消费 `OperationsHealthEventContract`，不成为业务内容或凭据的旁路入口。

## 7. 已确认决策

| 决策 | 选择 | 原因 |
| --- | --- | --- |
| 登录能力 | 通用账号管家 | 多种登录来源、多种执行器共用，避免与某软件强耦合 |
| 内容获取 | 深度通道优先、通用通道兜底 | 固定平台得到更深内容，同时保留广泛来源能力 |
| 通用结果 | 按能力范围说明 | 不把通用能力与深度能力差异误称为失败 |
| 工具关系 | 适配器可替换 | Agent 和业务流程不应依赖具体工具 |
| 运维官 | 脱敏观察与低风险恢复 | 防止登录/工具故障在多个 Agent 中重复发生 |

## 8. 风险与边界

- 平台可能要求验证码、二次验证、付费权限或拒绝访问；A君只请求用户处理或安全结束，不绕过；
- CookieBridge 可作为本机内部登录态输入适配器：它的原始值只在 loopback 的 CookieBridge → MediaCrawlerPro 单次调用中短暂存在，不得成为 Agent 公共 API；
- MediaCrawlerPro 能力、许可证、平台条款和 macOS 兼容性须在进入发行包前单独验证；
- 已登录或健康检查通过，不等于某条具体内容一定可读取或某项业务任务已经完成。
