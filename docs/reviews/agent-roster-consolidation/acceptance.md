## 6. 资源验证

| 指标 | 迁移前 | 迁移后 | 结论 |
| --- | ---: | ---: | --- |
| Gateway 主进程数 | 10 | 5 | PASS |
| Gateway 主进程 RSS | 约 839 MiB | 刚重启时瞬时约 1.69–1.96 GiB；空闲约两小时后约 558 MiB | PASS |
| Gateway MCP 子进程 | 基线未单独记录 | 8 个，约 308 MiB（重启前快照） | 无法同口径比较 |

刚重启时五个 Python Gateway 会同时载入解释器、依赖、Profile 状态和 MCP 配置，`ps` 的 RSS 还会把已驻留的共享映射分别计入进程，因此首轮快照明显偏高。空闲后 macOS 回收和压缩冷页，五个 Gateway 合计 RSS 回落到约 558 MiB，比迁移前约 839 MiB 低约 33%。正式运行数据目录当前仅约 2.4 MiB，不是瞬时 RSS 上升的来源。

磁盘侧主要是按设计保留的运行材料：活动 Hermes Profiles 约 371 MiB、隔离回滚 Profile 约 52 MiB、Hermes 日志约 24 MiB、迁移回滚材料约 1.7 MiB。Profile 中包含独立运行文件、技能、模型目录缓存和状态数据库；本轮没有删除它们来制造表面上的磁盘下降。
