## 尚未通过或未执行

- 首个候选岗位保持 `testing`，没有创建正式 Manifest、生产 Profile 或飞书路由。
- 一次小D公开视频业务已经真实交付到飞书文档，但“任务结束后稳定自动回到原会话提醒”尚未验证，不能称为完整聊天闭环。
- 普通批准、组织级拒绝、过期、重复点击和预算拦截仍缺真实飞书回归；不能把已验证的拒绝和组织级批准扩大表述为审批全部完成。
- Paperclip 的预算、跨员工长任务调度和完整审计仍未用真实业务验证。
- A君目前只对已接入的常见任务使用 AI 理解；未知需求不能伪装成已能自动完成。
