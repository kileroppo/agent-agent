## 1. 接手目标

- 目标：让所有 Agent 用稳定中文说明“现在怎样、结果是什么、下一步做什么”；新消息只给一个即时处理状态，任务可点击查看，运行控制可直接点击，长内容和表格在飞书手机端保持可读。
- 用户约束与不可做事项：飞书仍是日常入口；A君控制台不新建第二套任务队列；Paperclip 仍是组织级任务真相；未获授权不得代发真实飞书测试消息；链接不得包含 secret、token、Cookie 或用户标识。
- 做完的定义：真实飞书普通消息只出现一个处理图标且最终回复后消失；中文 `/new` 三按钮卡和运行中快捷控制卡生效；长分区回复有留白、短回复保持紧凑、长表不变形；任务短号可点击并打开准确记录。
- 唯一下一步：在真实飞书手机端看一条最新长回复，并在原任务卡点击一次“查看最新状态”；停止、审批和继续按钮只在专门受控任务中验收。A君与小D的普通消息处理图标无需重复测试。
- 允许继续的前提：先在运行 A君控制台的同一台 Mac 上验收链接；不要点击“以后不再询问”；手机验收前须另行配置安全可达的 `AJUN_TASK_DETAIL_BASE_URL`。
