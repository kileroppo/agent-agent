## 1. 接手目标

- 目标：让所有 Agent 用稳定中文说明“现在怎样、结果是什么、下一步做什么”；新消息只给一个即时处理状态，任务可点击查看，运行控制可直接点击，长内容和表格在飞书手机端保持可读。
- 用户约束与不可做事项：飞书仍是日常入口；A君控制台不新建第二套任务队列；Paperclip 仍是组织级任务真相；未获授权不得代发真实飞书测试消息；链接不得包含 secret、token、Cookie 或用户标识。
- 做完的定义：真实飞书普通消息只出现一个处理图标且最终回复后消失；中文 `/new` 三按钮卡和运行中快捷控制卡生效；长分区回复有留白、短回复保持紧凑、长表不变形；任务短号可点击并打开准确记录。
- 唯一下一步：在小办私聊发送一个普通问题，确认原消息上只出现一个处理图标且最终回复后消失，并观察长回复是否按分区和长条目自然留白。
- 允许继续的前提：先在运行 A君控制台的同一台 Mac 上验收链接；不要点击“以后不再询问”；手机验收前须另行配置安全可达的 `AJUN_TASK_DETAIL_BASE_URL`。

## 5. 风险、权限与关闭

- 当前阻塞或风险：处理图标需要飞书消息表情权限，图标、原生卡片和移动端排版仍需真实客户端验证；“停止当前任务”会真实停止运行，只能在受控测试任务中点击；当前详情链接指向本机回环地址，手机点击不可达是已知边界，不是已验证能力。
- 不得复制或展示的信息：任何模型 API Key、飞书 secret/token、Cookie、授权链接和真实用户标识。
- 需要谁确认：项目负责人在真实 A君飞书原会话确认。
- 关闭条件：普通消息只有一个处理图标且最终回复后消失；中文三按钮卡正常出现；“保留当前会话”不会丢失上下文；运行快捷按钮实际生效；手机端长表不再逐字竖排且长短内容密度合理；一条任务短号链接在同一台 Mac 打开准确任务；主回复没有英文内部状态或完整 UUID。
