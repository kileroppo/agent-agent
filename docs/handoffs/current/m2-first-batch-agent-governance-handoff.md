## 1. 接手目标

- 目标：完成第一批可从飞书手机端操作的 Agent 军团闭环。飞书是日常入口；Hermes 接收并派发；A君执行、诊断和恢复；Paperclip 只承担组织级治理。
- 用户约束与不可做事项：小D既有业务能力不重做；简单、低风险、单 Agent 请求不强制经过 Paperclip；不得把凭据、用户标识、Cookie、令牌或私密内容写入仓库、文档、日志或测试快照；不得把 A君扩成第二个组织、审批或审计控制台。
- 做完的定义：用户可在飞书与“ A君·军团总管”同一会话下发命令并收到同会话结果；创建 Agent 只形成草案，后续经 Paperclip 审核、隔离测试和真实验收才激活；高风险/组织级事项不能绕过 Paperclip。
- 唯一下一步：先用飞书官方 Channel SDK 做与现有 A君入口并行的受控收发接线，完成消息、卡片按钮、原会话回复和重复投递的自动检查；通过后再为一位已有真实交付能力的员工准备最小权限应用与协作群验收。当前 Hermes 入口保持运行，不因外部扫码、群聊或真人点击等待而停下其他开发。
- 允许继续的前提：保持测试为本机、受控、无外发、无真实账号连接；如发送内容会扩权、外发、公开发布或产生费用，先让所有者在飞书审批卡明确确认。
