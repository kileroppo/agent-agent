## 3. 变更与决策

- 已完成：
  - 专用产物不可被文字回报、状态字段或不可读引用替代；失配统一转 `waiting_test`。
  - 同一幂等键并发创建共享一次执行；同键换内容返回 `task_idempotency_conflict`。
  - 同一 `queued` 任务的普通执行与本地 PPT 通道由 JSON/SQLite 原子抢占，并发复现从 2 次执行降为 1 次。
  - 同一审批决定和同一暂停/继续请求共享单次下游动作；并发相反决定明确冲突，不覆盖已开始的副作用。
  - 重启只收敛前一进程卡在本地 starting 阶段的任务；不自动重做不确定副作用，不碰小D、Paperclip 或多人任务。
  - 飞书跟进文件的读改写已串行化；可能已送达但尚未落盘的完成通知标为 `delivery_uncertain` 并停止盲目重发，只允许本机按原任务和原会话显式确认“已送达”或“重试”。
  - 公共账号连接、验证结果和运营事件的完整变更已串行化；24 路并发不再损坏 JSON，磁盘失败会回滚内存且后续队列继续工作。
  - 小D任务创建、幂等查重和阶段更新共用事务队列；24 路并发只产生一个同键任务，输入漂移返回 `job_idempotency_conflict`，重启读回不丢阶段。
  - A君原生 JSON 入口将请求体限制为 1 MiB，畸形 JSON 返回 400、超限返回 413，均不会进入业务处理器。
  - 小D媒体、转录、确认稿、视觉证据和小办本地产物统一收紧为目录 `0700`、文件 `0600`。
