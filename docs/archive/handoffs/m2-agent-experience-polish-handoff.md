## 接手后先做什么

- 唯一下一步：下一次真实持续任务自然出现运行中卡片时，在手机点“查看任务详情”，确认详情在原卡内展开且不新建第二张卡；同时顺手检查长内容层级和任务链接。
- 允许继续的条件：只使用负责人自己的真实工作流；不代发消息，不点击真实审批、暂停或停止动作，不配置公网详情地址。
- 若当前没有持续任务，本交接没有技术、部署或自动复验动作。

## 已确定边界

- Paperclip 仍是组织级任务真相；不为飞书另建任务列表、会话库、审批系统或公网详情服务。
- 任务卡只用于持续进度、真实动作和可信交付；快任务、普通巡检和未声明岗位不扩张为常驻卡片。
- Profile 私有账本必须保持原子写入与 `0600`；缺可信锚点、跨 Profile、跨会话或 provider 结果不确定时失败关闭，不补发第二张卡。
- 共享 adapter 影响五个 Gateway，启用和回滚必须按 Profile；“停止当前任务”等真实动作只能在明确受控范围内点击。
- 不展示 secret、token、Cookie、授权链接或真实用户标识。
