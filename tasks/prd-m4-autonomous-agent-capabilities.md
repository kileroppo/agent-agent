> M5 纠偏：本文件最初设计的 A君本地 DAG、checkpoint、任务预算和 CapabilityGrant Store 已退出生产路径。11 个岗位及其开放任务入口继续保留；开放任务通过无状态映射复用岗位专用执行器，能力边界直接读取岗位 Manifest。组织计划、Issue、预算、审批与恢复统一使用 Paperclip，执行会话与运行检查点使用 Hermes。历史模块仅供迁移测试，不代表当前生产架构。

## 1. 目标

保留当前 11 个活动岗位，不合并“空心”或接近空心岗位。每个岗位同时具备：

- 可直接验收的岗位专有能力；
- 一个目标驱动的开放任务入口；
- 目标规范、动态计划、检查点、验证和有限重规划；
- 受审计的任务级能力发现与授权；
- 统一且可回退的推理模型策略。

完成不等于“Prompt 写得更强”，而是 Paperclip/Hermes 的同一任务账本中存在真实计划、授权、执行、产物与验证证据。

## 2. 范围

- 11 个活动 Manifest 增加专属开放任务、动态能力政策与自主预算；
- 主模型统一为 `stepfun/step-3.5-flash-2603`；`step-router-v1` 会路由其他厂商模型，不再作为 StepFun-only 主模型；
- 只有主模型传输不可用时回退 `deepseek/deepseek-v4-flash`；
- 开放任务复用岗位现有专有执行器，不建立第二套业务执行栈；
- 多人总任务支持最多 11 项显式依赖，同时执行不超过 4 项；
- 深化创建官、审核官、架构师、运维官和技术专家的结构化交付；
- 对小D、小R、小办、小拆、小创和 A君增加复杂任务入口。

## 3. 非目标

- 不自动复制或读取任何 `.env`、Key、Cookie 或登录态；
- 不因开放任务自动获得外发、发布、付款、生产变更或扩权；
- 不复制 Paperclip 的组织控制面、队列、预算或审批真相；
- 不让任务临时修改模型策略；
- 不以自动测试代替 StepFun/DeepSeek 真实传输、飞书或人工质量验收。

## 4. 核心流程

```text
目标
→ 开放任务无状态路由
→ Paperclip Issue / Pipeline 计划
→ Manifest 白名单检查与 Paperclip 能力审计
→ 执行专有能力
→ 产物验证与 Hermes / Paperclip checkpoint
→ 必要时由 Paperclip 有限重规划
→ 交付或如实停在待补充/待测试/待审批
```

多人目标由 A君建立一个父任务。每个子任务使用唯一 `key`，通过 `depends_on` 引用依赖；调度器只启动依赖已终结的分工，活动并发不超过 4。

## 5. 安全与预算

- 60 分钟；
- 20 次模型调用；
- 4 个并发子任务；
- 2 层委派；
- 最多 3 次失败重规划；
- 预计或实际费用超过 5 美元必须审批；
- 凭据、外部写入、付费动作、权限扩大一律审批；
- GoalSpec 输入、Paperclip checkpoint 和插件授权引用递归拒绝敏感字段。

## 6. 验收标准

- 11 个活动 Manifest/Profile 的主模型、回退模型和开放任务一致；
- 每个开放任务都能无状态路由到原岗位专有执行器，且不会生成 `autonomous_work_plan` 或本地能力授权产物；
- 已登记能力直接受岗位 Manifest 白名单约束；技能发现、审计和激活使用 Paperclip/插件正式授权；
- 未登记或敏感能力闭锁，不产生临时白名单；
- 原专有任务回归不退化；
- 11 项依赖任务的最大并发可被自动化证明不超过 4；
- 自动化测试、运行时、外部模型传输和人工岗位质量分别记账。

## 7. 当前验收边界

代码与契约实施本身不代表模型传输已验证。2026-07-30 已完成 11/11 Profile 的 StepFun 无副作用实调用，并在技术专家 Profile 完成 1 次受控 DeepSeek 自动回退；因此各 Profile 必须分别记录主传输和回退传输的验证状态，不能用单个回退探针宣称其余 10 个 DeepSeek 凭据也已逐个实调用。

同日继续完成 11/11 自主岗位各一条 StepFun 复杂任务，单岗位专有产物均通过门禁。首次跨岗位汇总在结构上覆盖 11 个来源任务，但出现事实一致性错误，已由新增语义门禁拒绝；A君实时 Prompt 随后补充“同一对象、同一指标、同一时间范围才能判冲突”的收敛规则。获批的唯一修复后回归调用接受了 11/11 岗位产物、未把已完成任务重标为未完成，并明确说明自动化测试数与岗位运行状态数维度不同、不构成矛盾。一次本地门禁因两组数字同时出现而误判，修正为识别“明确区分维度”的表述后，回归结果全部通过；该复核没有追加模型调用。M4 本地岗位质量与模型回归已关闭，飞书/Paperclip 外部交付仍保持未执行。
