ONE PHONE / ONE COMMAND CENTER

你在飞书发令，
Mac 上的军团自己分工。

日常任务不必进入 A君网页；你只和一个“军团总管”说话。它把命令交给 Mac 上的 Hermes 和各个 Agent，需要你做决定时，再把审批卡发回手机。

看图时先检验这一点你是否能只用飞书完成：下任务、看进度、批准高风险动作、拿到交付？如果任何一步要求你回 Mac 网页，体验就还没闭环。
日常命令与回报Mac 本地执行需要治理/审批不能越过的边界

03 / 只在需要时治理

Paperclip

组织级总控

新 Agent、权限扩展、对外发布、预算、长任务、跨 Agent 协作才进入这里。

审批回飞书

你手机决定

飞书只给你一张能看懂、能点的审批卡；普通一次性审批由 A君记录，组织级审批才由 Paperclip 记账。

不应进入 Paperclip：查一次健康、重试一个已知失败、小D处理已有授权的素材，以及一次性、范围明确的普通批准。
当前缺口：小D飞书入口与“创建 Agent”路由已有基础；统一军团总管、飞书审批卡和按钮回调尚未完成。

这张图的判断标准：飞书负责“你看见和决定什么”；Hermes 负责“消息怎么到 Mac”；A君负责“Mac 能安全做什么”；Paperclip 负责“哪些事必须留下组织级审批和审计”。

什么情况下改道去 Paperclip？ 任务涉及新 Agent、权限/账号、对外发布、花钱、长时间协作、暂停终止或跨 Agent 审计时，才创建组织级任务与审批。

手机体验：正常任务从你发出到交付都只在一个飞书会话里完成。你只在系统要你做“有影响的决定”时被打断。
