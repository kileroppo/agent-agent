业务 Agent

只声明任务与所需动作，例如读取媒体元数据、获取已授权视频、下载字幕。

connectionId + operation + source
最小权限平台无关
◎

任务与治理

记录真实阶段、脱敏审计与失败分类；飞书消息只是投影，不是任务真相。

needs_input：需要用户授权
waiting_approval：范围待确认
manual：平台需要人工处理

Connection Broker

唯一的授权网关。它不是 AI，也不替用户登录；它只执行已获授予的、确定性的连接能力。

连接身份connectionId、平台、账户别名、状态
动作范围只读 / 下载 / 数据范围 / 有效期
调用主体allowedAgentIds 与审批策略
健康与审计脱敏健康、失败事件、可撤销
ConnectionBroker.execute(connectionId, operation, source)
允许 → 选择受限适配器并返回 SourceAssetRef / SubtitleRef
拒绝 → 返回 needs_input、waiting_approval 或脱敏失败原因
没有策略通过，就没有平台调用；没有任何接口把原始 Cookie、token 或浏览器会话返回给 Agent。
